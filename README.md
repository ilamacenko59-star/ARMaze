# AR Maze — AR-лабиринт с шариком

AR-игра для Android на Unity и Vuforia: наводишь камеру телефона на картинку-метку — на ней появляется 3D-лабиринт из кирпичных стен. Наклоняй телефон (или води пальцем), чтобы докатить шарик до лунки-финиша.

## Как играть

1. Запусти игру и наведи камеру на картинку с лабиринтом (метка из базы `camera`).
2. На картинке появится лабиринт с шариком.
3. Наклоняй телефон — шарик катится в сторону наклона. На ПК в редакторе: стрелки/WASD или мышь.
4. Закати шарик в чёрную лунку — появится надпись **WIN**, конфетти и звук.
5. Если метка пропадает из кадра — игра ставится на паузу.

## Особенности

- **Стабильная физика в AR.** Vuforia каждый кадр «переставляет» лабиринт вслед за картинкой, из-за чего шарик мог проходить сквозь стены. Поэтому физика шарика считается в невидимой неподвижной копии лабиринта, а видимый шарик просто повторяет её позицию. Плюс невидимая «крышка» над стенами, непрерывные столкновения, ограничение скорости и респаун.
- **Управление наклоном** с калибровкой «нулевого» положения телефона, а также клавиатура, мышь и касания.
- **Звук качения** шарика, экран победы с анимацией и конфетти.

## Как открыть и собрать

Нужен Unity **6000.6.0f1** с модулем **Android Build Support**.

1. **Скачай Vuforia Engine 11.4.4** — его нет в репозитории (файл 132 МБ, и лицензия Vuforia запрещает его распространять):
   зарегистрируйся на [developer.vuforia.com](https://developer.vuforia.com/downloads/sdk), скачай *Vuforia Engine for Unity* и положи файл `com.ptc.vuforia.engine-11.4.4.tgz` в папку `Packages/`.
2. **Получи свой лицензионный ключ Vuforia** (бесплатный Basic): developer.vuforia.com → *Plan & Licenses* → *Generate Basic License*.
   Ключ из репозитория убран — без своего ключа камера в AR работать не будет.
3. Открой проект в Unity Hub.
4. Вставь ключ: **Window → Vuforia Engine → Vuforia Configuration → App License Key**.
5. **File → Build Profiles → Android → Build**.
